Software de gestión para fisioterapia

Todo lo que necesita una clínica, en un solo programa.

Clínica Fisio es una aplicación de escritorio para Windows que reúne la gestión clínica, la organización del trabajo y la gestión económica de centros de fisioterapia.

El producto

Una base de software preparada para continuar evolucionando.

Existe una versión DEMO independiente con datos ficticios y un dossier profesional para presentar y valorar el producto.

Se estudian posibilidades de adquisición, integración o continuidad del desarrollo.

Nota sobre Veri*Factu
El producto incorpora funcionalidades relacionadas con Veri*Factu. El envío real a la AEAT no está validado y permanece pendiente de las comprobaciones y puesta en producción correspondientes. No se presenta como una integración certificada o plenamente operativa.
